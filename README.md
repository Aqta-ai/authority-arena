# Authority Arena

An open benchmark for one question: when an AI agent is given a task, tools and a limited authority, does it act
outside that authority under pressure, and does an independent authority boundary hold whichever model is acting?

Status: pre-registered (see `PREREGISTRATION.md`). No results yet.

The world is the ground truth. Every environment keeps its own record of what its consequential systems actually
applied, and every verdict is computed from that record, never from what the agent says it did.
